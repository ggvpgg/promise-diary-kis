# Дневник обещаний

Гайдеек Валерий Егорович  
Задание №5

Приложение для записи дел и обещаний. У каждого дела есть дата обещания, срок выполнения и комментарии. Дела можно искать, смотреть на выбранный день, неделю или месяц и отмечать выполненными.

## Как запустить

Нужен macOS и Python 3. Готовую сборку `Дневник обещаний.app` для Mac с Apple Silicon можно просто открыть, Python для неё не нужен.

Запуск из исходников:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Чтобы собрать `.app` самостоятельно:

```sh
pip install pyinstaller
pyinstaller --noconfirm --windowed --name PromiseDiary --osx-bundle-identifier ru.kis.promisediary --icon icon.icns main.py
```

Сборка появится в `dist/PromiseDiary.app`.

## Как устроено

Написал приложение на PySide6. Вся логика находится в `main.py`, сервер и база данных не нужны. Приложение работает без интернета и после закрытия окна остаётся в строке меню macOS.

Дела лежат в `~/Library/Application Support/PromiseDiary`. Каждое дело хранится в отдельном JSON-файле. Поэтому если один файл повредится, остальные всё равно откроются. Запись сначала идёт во временный файл, затем он заменяет старый. Несохранённый текст и комментарий сохраняются в черновик. Если сохранить файл не получилось, введённый текст остаётся в окне.

Фильтр по дню, неделе и месяцу использует срок выполнения дела. Для запуска с другим каталогом данных можно задать переменную `PROMISE_DIARY_DATA_DIR`.
